# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, message [@forhad71 on Telegram](https://t.me/forhad71) or use GitHub's [private vulnerability reporting](https://github.com/ForhadHossain71/whatsapp-web-privacy-blur/security/advisories/new) with:

- A description of the issue and its impact
- Steps to reproduce
- The extension version and browser you used

You can expect a reply within a few days. Once the issue is confirmed, a fix will be released as soon as possible and you will be credited in the changelog if you wish.
